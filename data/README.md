# Шпаргалка по данным расписания

Все JSON-файлы сайта лежат в этой папке. Здесь — как их редактировать.

---

## `schedule.json` — базовое расписание

Два блока: `odd` (нечётная неделя) и `even` (чётная неделя). Внутри — дни с массивом пар.

Каждая пара:
```json
{
  "id": "odd-mon-1",
  "time": "08:00",
  "subject": "Физика (лаб.)",
  "teacher": "Осинцев Алексей Михайлович",
  "room": "7433",
  "subgroup": 0
}
```

- `id` — уникальный код пары (нужен для Д/З и overrides). Не меняй без причины.
- `subgroup`: `0` — для всех, `1` или `2` — конкретная подгруппа.
- Поля `teacher` и `room` необязательные.

---

## `homework.json` — домашние задания

Структура: **номер недели → id пары → текст Д/З**.

```json
{
  "5": {
    "even-mon-1": "§12, задачи 1-5",
    "odd-thu-1": "Конспект главы 3"
  },
  "6": {
    "even-tue-1": "Подготовиться к семинару"
  }
}
```

- Ключ — **номер недели** (тот, что показывает сайт в шапке).
- Внутри — пары по их `id` из `schedule.json`.
- Если для недели Д/З нет — недели вообще может не быть в файле.
- Пустая строка `""` = «Домашнее задание не указано».

---

## `overrides.json` — оперативные правки

Структура: **номер недели → массив правил**.

```json
{
  "5": [
    { "action": "cancel", "id": "odd-wed-1" },
    { "action": "note", "id": "odd-fri-2", "note": "Перенос в ауд. 8105" }
  ]
}
```

### Типы правил

**Отменить пару:**
```json
{ "action": "cancel", "id": "odd-wed-1" }
```
Пара полностью исчезает с экрана на этой неделе.

**Пометка рядом с парой (красная плашка):**
```json
{ "action": "note", "id": "odd-fri-2", "note": "Начало в 14:00" }
```
Пара остаётся, но появляется красный бейдж. Для переносов, замен, опозданий.

### Несколько правок на одну неделю

```json
{
  "5": [
    { "action": "cancel", "id": "odd-wed-1" },
    { "action": "cancel", "id": "odd-wed-2" },
    { "action": "note", "id": "odd-fri-2", "note": "Перенос в 8105" }
  ]
}
```

### Важно

- **Правила действуют только на указанную неделю.** На следующей — снова обычное расписание.
- `id` должен **точно совпадать** с `schedule.json` (одна опечатка = правило не сработает).
- Если недели нет в файле — правок нет.

---

## `books.json` — учебники

Предмет → список ссылок.

```json
{
  "Математика": [
    { "title": "Алгебра и начала анализа", "url": "https://disk.yandex.ru/d/..." }
  ]
}
```

Открывается по кнопке 📚 в шапке сайта.

---

## `info.json` — важная информация

Список объявлений. Открывается по кнопке ❗.

```json
{
  "items": [
    { "date": "2025-10-05", "text": "5 октября пары с 15:30 отменяются" }
  ]
}
```

Дата необязательна.
